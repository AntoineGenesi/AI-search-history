# Action Proof

## Chronology Gate

Open an independently identified original raw/session/tool source first.
Current-loop, evaluator, benchmark, report, review, prompt, and prior-final
material is diagnostic only after original source evidence is open; never
primary proof.

Inspect `source_window_action_proof` and `tool_action_proof`.
Tool calls/outputs, diffs, commits, tests can prove actions; assistant prose and
later summaries are leads. Stop once primary evidence answers the named action;
widen only for missing facets; state caps.
