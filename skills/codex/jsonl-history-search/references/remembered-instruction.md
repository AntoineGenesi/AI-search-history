# Remembered Instruction Or Preference

Use when the user asks what they previously told the agent or which preference
they expressed.

Open original user-authored source refs before answering. Group repeated
wording when useful, distinguish the user's words from later paraphrases, and
state searched-scope limits. If no primary user turn is available, fail closed
and ask for an approximate topic, time, or session anchor. Do not reconstruct a
remembered instruction from summaries or unrelated local artifacts.
