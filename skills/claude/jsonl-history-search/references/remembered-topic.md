# Remembered Topic Or Rationale

Use when the user asks why they mentioned a topic or what they meant by it.

Run the router, open its primary source follow-through, and read enough
surrounding turns to recover the reason rather than matching one sentence.
Prefer the original discussion over later prompt echoes or summaries. Preserve
user corrections when the agent previously misunderstood. Stop after the
inspected window supports the rationale, and label inference when it does not.
