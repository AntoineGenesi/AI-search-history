# Release history

This release retains filtered runtime and agent-skill development history. Only two selected source ancestries were imported into an independent repository; no original tags, remote branches or local object links are inherited.

Private conversations, test fixtures, evaluation inputs, reports, task state, and historical documentation were excluded. Public documentation was curated for the current release. Historical runtime text was sanitized for configured private paths, identities, session UUIDs, credentials and abusive language. Binaries and non-regular files were omitted.

Commit author/committer identities and messages are generic. Dates, retained code changes and surviving branch topology remain; private-only commits may disappear. This is filtered provenance, not the complete private development record.

The shared rewrite mapped 8,768 source commits. The default release is `release-2026-11-24`; `experimental-bounded-readback` is a separately retained experimental implementation. See [performance](performance.md) for the limits of historical measurements.
